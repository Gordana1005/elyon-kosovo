# Барање за нов извоз од collabBox

> Оваа страница е подготвена за испраќање до лицето што има пристап до collabBox.
> Целта е да ги внесеме **сите платени нарачки** во новиот CRM.

## Зошто ни треба нов извоз

Од collabBox добивме два фајла:

| Фајл | Редови | Што содржи |
|---|---:|---|
| `LeadIn - Pending orders.xls` | 41.646 | платени **први** нарачки од клиенти дојдени преку афилијат |
| `LeadOut - Predikcii.xls` | 3.581 | платени **повторни** нарачки од предикциски листи |

Двата фајла имаат само осум пополнети колони:

> Ред.Бр. · Наслов на документ · Тип · Комитент · Износ · Валута · Датум и време · Автор

**Недостасуваат двете најважни колони: телефонскиот број и производот.**

Во CRM-от телефонскиот број е единствениот идентификатор на клиентот — целата
историја, сите предикциски листи и секое досие се градат врз него. Без него
нарачката не може да се внесе воопшто.

## Што направивме во меѓувреме

Ги споивме документите од collabBox со 81.657 нарачки извезени од AlterCPA,
спарувајќи по **име + датум (прозорец од 5 дена)**, бидејќи тоа е единственото
заедничко поле.

Резултат: **само 4.881 од 45.227 документи (10,8%)** најдоа пар. Од нив 2.621
нарачки беа поправени од „откажана" во „платена".

Останатите **над 40.000 платени нарачки не можат да се внесат** — не затоа што
не сакаме, туку затоа што во извозот нема телефон ниту производ.

## Што бараме

Истите два прегледа, со **истиот филтер**, но со додадени колони:

| Колона | Задолжително | Забелешка |
|---|---|---|
| **Телефон на комитентот** | ✅ **ДА** | Во кој било формат — `070123456`, `+389 70 123 456`, `38970123456`. Само внимавајте да е форматирана како **текст**, за да не се претвори во `7.01235E+8`. |
| **Производ / артикл** | ✅ **ДА** | Името на производот. Ако нарачката има повеќе производи — по еден ред за секој, со ист број на документ. |
| **Количина** | препорачливо | Ако недостига, се смета 1. |
| Наслов на документ | ✅ задржете | Ова е клучот за да не се дуплираат при повторно внесување. |
| Комитент (`#шифра Име`) | ✅ задржете | |
| Износ и Валута | ✅ задржете | |
| Датум и време | ✅ задржете | |
| Автор | ✅ задржете | |
| **Статус на нарачката** | препорачливо | Платена / вратена / испратена — ако постои такво поле. |
| **Адреса и град** | по желба | Го подобрува досието на клиентот. |
| **Број на нарачка од AlterCPA** | по желба, но **многу вредно** | Ако collabBox го чува бројот од AlterCPA, спарувањето станува точно 100% наместо 10,8%. |

### Ако не може да се додадат колони во истиот преглед

Тогаш ни треба **посебен извоз на комитентите**:

> `Шифра на комитент` · `Име` · `Телефон` · (`Град`, `Адреса` ако ги има)

Со него шифрите `#173211` од постојните фајлови се поврзуваат со телефон, и
29.813 клиенти од `LeadIn` стануваат употребливи. Производот сепак ќе недостига,
но нарачките ќе можат да се внесат.

## Формат

- `.xlsx` или `.csv` (ако е CSV — **UTF-8**, за да не се расипе кирилицата)
- Прв ред = заглавие
- Ист временски опсег: **март 2025 → денес**
- Нема ограничување на големина

## Пред целосниот извоз

Испратете **20–30 реда како примерок**. Ќе ги провериме заглавијата и форматот
на телефонот пред да го подготвите целиот фајл — така се избегнува двојна работа.
